# FORESIGHT - Enterprise AI Dashboard

**Enterprise AI Dashboard with Google OAuth, Real-time Analytics, and AI Predictions**

## Features

- 🔐 Google OAuth 2.0 Login
- 📊 Real-time Dashboard with 20+ metrics
- 🤖 AI Predictions (7-day forecast)
- 📈 Interactive Charts (Chart.js)
- 📦 Inventory Management
- 📤 CSV/Excel Data Upload
- 📋 Report Generation (CSV)
- ⚙️ User Profile & Settings
- 🌐 Multi-currency (USD to INR)
- 🎨 Premium UI with Emerald theme

## Tech Stack

- Python 3.11+ | FastAPI | Google OAuth 2.0
- HTML5 | CSS3 | JavaScript | Chart.js
- Pandas | NumPy | JWT | bcrypt

## Deployment

Deploy on Render.com:
1. Push code to GitHub
2. Connect to Render
3. Build: pip install -r requirements.txt
4. Start: uvicorn main:app --host 0.0.0.0 --port \
